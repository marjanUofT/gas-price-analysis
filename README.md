# Gas Price & Real Estate Analysis

## Overview
This project analyzes gas price trends and real estate sales data using Python. It includes data cleaning, custom interpolation, statistical analysis, and time-series visualization.

## Features
- Custom interpolation for missing values (without built-in functions)
- Statistical analysis (mean, median, skewness, kurtosis)
- Time-series aggregation (monthly trends)
- Seasonal analysis
- Data visualization

## Tech Stack
- Python
- pandas
- numpy
- matplotlib
